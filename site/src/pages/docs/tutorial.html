Tutorial

Pay-if-verified on Celo Sepolia in 10 minutes

You'll install the CLI, fund a test wallet, pay a service only if its answer checks out, and then re-check that call with no wallet. Everything here uses test money.

Coming. The buyer commands aren't built yet. attessa init, attessa call and attessa verify are coming; until then, this tutorial shows what they will do.

You need Node.js 22 or later, pnpm (corepack enable), git and a terminal. No browser wallet.

  1. Install

    Attessa isn't on npm. This builds it from source and puts attessa on your PATH. If pnpm says there is no global bin directory, run pnpm setup, open a new terminal, and run the last line again.

  2. Set up with attessa init

    This creates a wallet for this computer, keeps the key in your OS keychain, and sets spending limits. It starts on Celo Sepolia.

    Already have a key? Set ATTESSA_PRIVATE_KEY or pass --keystore <file> and Attessa uses it instead.

  3. Get test funds

    • Gas: faucet.celo.org/celo-sepolia
    • Test USDC: faucet.circle.com, then choose Celo Sepolia

    Paste the address attessa init printed into both. The test USDC pays for calls. The CELO is for gas only if you ever cancel a payment permission on chain yourself; signing a permission is free.

  4. Make a call with attessa call

    Point it at an attested service and give it the request body. Attessa checks the seller, shows the price, and asks you to sign a payment permission. Money only moves if the answer's proof checks out.

    The demo service is a payment check: send it the address you're about to pay and it answers allow, review or deny, with reasons. Its address is [[slot:demoServiceUrl]] once it's live. Save this as tx.json (any name works), with the address you want checked in payTo, in lowercase:

    Here is what a successful call prints, against an illustrative service:

    {{> cli-call}}

    The answer lands in result.json in the folder you ran the command from.

    If the answer had been tampered with, you would see this instead, ending once Celo shows your permission expired unused:

    {{> cli-refused}}

  5. Re-check it with attessa verify

    Every call adds one line to your record, ~/.attessa/evidence.jsonl. The newest line is the call you just made, and its entry ID is the request ID: 0x followed by 64 hex characters. Check that call again from public Celo data and the proof the service's gateway publishes for that request ID. This needs no wallet and no payment, so anyone can do it.

    It runs the same five checks as the proof explorer (approved build, sealed machine, this exact request and answer, real Celo data, and payment), marks each one passed, failed or not applicable, and ends with one verdict: verified, rejected with the failing check named, or unattested. You can paste the same ID into the explorer instead.

What you did

You paid a service only after its answer was signed by the build its owner approved, and you re-checked, from Celo and the proof the gateway published, which approved build answered. The link from that build to its source code stays the owner's claim until someone reproduces the build.
