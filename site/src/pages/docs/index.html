Attessa docs

Attessa is a check your agent runs before paying for a service: pay only if the answer was signed by the build the seller approved, running in hardware the seller can't tamper with. The docs come in four kinds. Pick the one that matches what you need right now.

TutorialMake your first pay-if-verified call on Celo Sepolia, in about 10 minutes. Coming: the buyer commands aren't built yet. Words used in these docs

WordMeaning
AttestedThe answer carries a proof.
VerifiedA proof passed every check against the registry.
UnattestedNo proof was offered, so there is nothing to check.
RejectedA named check failed.
Approved buildA build the agent's owner approved on Celo. In the contracts and SDK it's a release, identified by the measurements PCR0 to PCR2.
Sealed machineAn AWS Nitro enclave: its running code is measured, and the operator can't log in or change it.
SignerThe key a sealed machine makes when it starts, registered on Celo with AWS's attestation.
ProofAn EIP-712 signature by the signer that binds a request, its answer, the inputs and the payment to the approved build.
Pay, settlePay is the plain word. Settle is the technical step: the gateway takes the payment on chain.
CancelVoid an unused payment permission on chain before it expires.
