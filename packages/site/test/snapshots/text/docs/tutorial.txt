Pay-if-verified on Celo Sepolia
No public seller is live yet, so you can't complete the paid call today. You can install the CLI and set up a wallet now. This page shows how the rest will go.
You'll install the CLI, fund a test wallet, pay a service only if its answer checks out, and then re-check that call with no wallet. Everything here uses test money.
attessa init and attessa call are built. Coming. attessa verify isn't built yet, so the last step shows what it will do. The output shown for init and call is the CLI's, from FLOWS; the service in it is illustrative, because the demo service isn't live yet.
You need Node.js 22.14 or later, pnpm (corepack enable), git and a terminal. No browser wallet.
Install
Terminal
Copy
$ git clone https://github.com/jesterkeri/attessa -b staging
$ cd attessa
$ pnpm install --frozen-lockfile && pnpm -r build
$ cd packages/cli && pnpm link --global
Attessa isn't on npm. Until launch the code is on the staging branch. This builds it from source and puts attessa on your PATH. If pnpm says there is no global bin directory, run pnpm setup, open a new terminal, and run the last line again.
Set up with attessa init
This sets up your wallet and spending limits, and starts on Celo Sepolia. A source build has no OS keychain, because the optional keytar package is not installed, so set ATTESSA_PRIVATE_KEY or pass --keystore <file> first. With neither, it tells you no wallet was created. The output below is what you see when a keychain is available.
Example output
Copy
$ attessa init
→ attessa checks which build a service runs before you pay it, and only pays if the answer checks out.

Already have a key? Set ATTESSA_PRIVATE_KEY or pass --keystore <file> and Attessa uses it instead.
Get test funds
Gas: faucet.celo.org/celo-sepolia
Test USDC: faucet.circle.com, then choose Celo Sepolia
Paste the address attessa init printed into both. The test USDC pays for calls. The CELO is for gas only if you ever cancel a payment permission on chain yourself; signing a permission is free.
Make a call with attessa call
Point it at an attested service and give it the request body. Attessa checks the seller, shows the price, and signs a payment permission within your limits. Money only moves if the answer's proof checks out.
The demo service is a payment check: send it the address you're about to pay and it answers allow, review or deny, with reasons. Its address is {demoServiceUrl}sample
once it's live. Save this as tx.json (any name works), with the address you want checked in payTo, in lowercase:
tx.json
Copy
{
"chainId": "11142220",
"payTo": "0x<40 lowercase hex characters>",
"asset": "0x01c5c0122039549ad1493b8220cabedd739bc44e",
"amount": "1000000"
}
11142220 is Celo Sepolia, asset is its test USDC, and amount is in USDC's six-decimal units, so 1000000 is 1 USDC.
Terminal
Copy
$ attessa call {demoServiceUrl}/v1/evaluate --body tx.json

Re-check it with attessa verify Coming
Coming. attessa verify isn't built yet; this step shows what it will do.
Every call adds one line to your record, ~/.attessa/evidence.jsonl. The newest line is the call you just made, and its entry ID is the request ID: 0x followed by 64 hex characters. Check that call again against public Celo data, using your record. This needs no payment.
Terminal (coming)
Copy
$ attessa verify <requestId>
It checks what your record and Celo can show: that the build your record names was approved, and its signer registered, when the call settled, and that the payment settled or your permission expired unused. It marks each check passed, failed or not applicable, and ends with one verdict: verified, rejected with the failing check named, or unattested. Your record keeps the proof's hashes but not its signature, so the request, answer and Celo data checks are the ones your agent ran when it paid. You can also paste the call's settlement transaction into the proof explorer to check its payment.
What you did
You paid a service only after its answer was signed by the build its owner approved, and you re-checked on Celo that the build your record names was approved when the call settled. The link from that build to its source code stays the owner's claim until someone reproduces the build.
