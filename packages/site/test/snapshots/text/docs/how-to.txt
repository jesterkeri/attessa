How-tos
Short recipes for one job each. They assume you've done the tutorial or know the basics.
Run a seller
Sell an API that buyers can check before paying: you approve a build of your code, run it in a sealed AWS machine, and register that machine's key on Celo. Every transaction shows its CELO cost and asks before it sends. Every command in this guide is built.
Register your agent's public identity (ERC-8004).
On your AWS host, build the sealed machine image from the commit you'll publish.
Approve that build on Celo.
Add the endpoint buyers will call and the address they'll pay.
Start the sealed machine.
Register its signer, within 30 minutes of starting it.
Seller commands
Copy
$ attessa agent register --name "Acme risk check"
$ attessa enclave build
$ attessa release approve --agent 412 --from-build build/measurements.json --source https://github.com/acme/risk/commit/a1b2c3d
$ attessa endpoint add --agent 412 --origin https://risk.example --pay-to 0xGATE…01
$ attessa enclave start --agent 412 --origin https://risk.example
$ attessa signer register --agent 412 --attestation att.bin
Use an enclave-enabled instance. For example c6g.xlarge with --enclave-options Enabled=true. Debug mode isn't accepted: AWS doesn't sign for it.
A signer is valid until its expiry or until the machine restarts. Renew a running one with attessa signer renew. After a restart, the machine has a new key, so run attessa enclave start and attessa signer register again.
If registration is refused
The report is too old. Celo accepts reports up to 30 minutes old. Run attessa signer register --fresh on the same machine; no restart needed.
Wrong build. The machine runs a build your agent hasn't approved. Approve it with attessa release approve, or start the approved build.
Debug mode. Start the machine without --debug-mode.
Revoke a build or a signer
Revoking a build stops buyers paying for answers from it. Its live signers stop working within 60 seconds, and your endpoint refuses calls until you approve and register another build. Revoking is permanent.
Terminal
Copy
$ attessa release revoke <releaseId>
$ attessa revoke signer <signerAddress>
Run them from the agent owner's wallet. attessa status --agent <id> lists your releases, endpoints and signers with their states.
Use Attessa from an MCP-capable agent
The Attessa MCP server gives your agent nine tools over stdio, with the same bounds as the CLI: a limit per call and a cap per day. There is no published package: build this repository (pnpm install --frozen-lockfile && pnpm -r build, as in the install steps) and point your agent's MCP client at packages/mcp/dist/bin.js in your clone.
The server reads the same wallet as the CLI: ATTESSA_PRIVATE_KEY, or a keystore (ATTESSA_KEYSTORE with ATTESSA_KEYSTORE_PASSWORD). The OS keychain is used only if the optional keytar package is installed, and a source build doesn't install it. ATTESSA_NETWORK, ATTESSA_RPC, ATTESSA_REGISTRY and ATTESSA_DATA_DIR work as the CLI's network, RPC, registry and data-folder settings. Name more variables to hide in ATTESSA_REDACT (comma-separated). The server removes the wallet secrets from its own process environment at start and hides matching secrets in what it returns. That matching is best effort, not a guarantee, so use a keystore holding a low-balance wallet rather than a key in the environment.
MCP client config
Copy
{
"mcpServers": {
"attessa": {
"command": "node",
"args": ["/path/to/attessa/packages/mcp/dist/bin.js"]
}
}
}
Two tools spend or send, and say so in their descriptions: pay_and_verify signs a payment within your bounds, and cancel_authorization sends a transaction. get_result and status sign a payer message, with no payment and no transaction. Run attessa init first, or pass maxAmount on each paid call. The full list is in the reference.
Use it with buy
Optional, not built yet. buy (usebuy.ai) is Celo's marketplace of pay-per-call APIs for agents. It takes payment before it calls the service, so a call through buy isn't protected by the check: you pay even if the answer fails it. Attessa still records what you got.
Example output (not built yet)
Copy
$ attessa call --via buy https://<buy-capability>
→ Price: 0.005 USDC. buy (usebuy.ai, Celo's pay-per-call API marketplace) takes payment before the service runs, so this call isn't protected by the check: you pay even if the answer fails it. [pay/cancel]
→ Paid 0.005 USDC through buy (tx 0x…)
→ No proof offered: this service doesn't say which code produced its answer, so it can't be checked (unattested)
Answer saved. Record: ~/.attessa/evidence.jsonl
No payment protection in this mode. buy has no refunds. If a service fails after payment, your record has the transaction to show buy.
