Attessa lets an agent pay a service only when the answer is signed by the code the seller approved. Paste a call's settlement transaction, and the explorer checks its payment from public Celo data: who paid, which address was paid, how much, and in which block. An address alone doesn't tell which endpoint or build answered; that needs the call's proof. No wallet, no payment. Planned: looking a call up by its request ID and checking its proof, which needs a public copy of the proof that nothing serves yet.
