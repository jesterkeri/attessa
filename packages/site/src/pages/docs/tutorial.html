Tutorial

Pay-if-verified on Celo Sepolia in 10 minutes

You'll install the CLI, fund a test wallet, pay a service only if its answer checks out, and then re-check that call with no wallet. Everything here uses test money.

attessa init, attessa call and attessa verify are built. The output shown for init and call is the CLI's, from FLOWS; the service in it is illustrative, because the demo service isn't live yet.

You need Node.js 22.13 or later, pnpm (corepack enable), git and a terminal. No browser wallet.

  1. Install

    Attessa isn't on npm. Until launch the code is on the staging branch. This builds it from source and puts attessa on your PATH. If pnpm says there is no global bin directory, run pnpm setup, open a new terminal, and run the last line again.

  2. Set up with attessa init

    This creates a wallet for this computer, keeps the key in your OS keychain, and sets spending limits. It starts on Celo Sepolia.

    Already have a key? Set ATTESSA_PRIVATE_KEY or pass --keystore <file> and Attessa uses it instead.

  3. Get test funds

    • Gas: faucet.celo.org/celo-sepolia
    • Test USDC: faucet.circle.com, then choose Celo Sepolia

    Paste the address attessa init printed into both. The test USDC pays for calls. The CELO is for gas only if you ever cancel a payment permission on chain yourself; signing a permission is free.

  4. Make a call with attessa call

    Point it at an attested service and give it the request body. Attessa checks the seller, shows the price, and signs a payment permission within your limits. Money only moves if the answer's proof checks out.

    The demo service is a payment check: send it the address you're about to pay and it answers allow, review or deny, with reasons. Its address is [[slot:demoServiceUrl]] once it's live. Save this as tx.json (any name works), with the address you want checked in payTo, in lowercase:

    Here is what a successful call prints, against an illustrative service:

    {{> cli-call}}

    The answer lands in result.json in the folder you ran the command from.

    If the answer had been tampered with, you would see this instead, ending once Celo shows your permission expired unused:

    {{> cli-refused}}

  5. Re-check it with attessa verify

    Every call adds one line to your record, ~/.attessa/evidence.jsonl. The newest line is the call you just made, and its entry ID is the request ID: 0x followed by 64 hex characters. Check that call again against public Celo data, using your record. This needs no payment.

    It prints one line for each of six checks: release, signer, signature, binding, timing and inputs, and settlement. Each says pass, FAIL or not checked, with its Celoscan link. Your record keeps the proof's hashes but not its signature, so without the proof header and the answer you kept, the proof checks print as not checked and it ends with "Not fully verified". With them, run attessa verify <requestId> --proof <file> --response <file>; it ends with "Verified: every check passed." only if all six pass. Once the proof explorer is live, you will be able to paste the call's settlement transaction there to check its on-chain part.

What you did

You paid a service only after its answer was signed by the build its owner approved, and you re-checked on Celo that the build your record names was approved when the call settled. The link from that build to its source code stays the owner's claim until someone reproduces the build.
