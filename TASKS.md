# Tasks (r5)

One line per task. The id links a task to its evidence in DONE.md. A task isn't complete until its verification command has run and its real output is in DONE.md.

Format: `- [ ] Tnn <what> | verify: <exact command> | done when: <observable condition>`

Commands run from the repo root unless they start with `cd`. `$SEP` = `https://forno.celo-sepolia.celo-testnet.org`, `$MAIN` = `https://forno.celo.org`.

**Broadcasts are Joshua's.** The harness blocks `--broadcast`. You prepare the script and run the simulation; Joshua runs the broadcast and pastes the tx hash.

**Spike results** come back to the design session through OPEN-QUESTIONS.md, before the gate closes.

**Dates and cut list:** SPEC §13. G1 Oct 21, G2 Oct 24, S3 Oct 26, G3+4 Oct 30, G5 Nov 2 (USA₮ by Nov 6), G6 Nov 8. Signers are renewed (`attessa signer renew`) whenever fewer than 72 h remain (cron alert), so neither network's signer ever expires; on Nov 8 both must cover Nov 14.
